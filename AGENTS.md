# Project Instructions

When running in agent mode do not run a dev server (npm run dev, npm run dev:tenis, npm run dev:academy). User has it running already.

This is an npm workspaces monorepo (see README.md): `apps/kapusz-tenis`, `apps/academy`, `packages/brand`, `packages/ui`, `packages/booking`. Run commands from the repo root; verify changes with `npm run check`, `npm test` and `npm run build`.
